# 🤖 Machine Learning Algorithms in Python

This repository contains implementations of fundamental Machine Learning algorithms using Python and Scikit-learn. These programs were developed as part of academic laboratory exercises and provide hands-on experience with supervised and unsupervised learning techniques.

---

## 📚 Algorithms Included

| Algorithm | Description |
|-----------|-------------|
| 📈 Linear Regression | Predicts continuous values using a linear relationship between variables. |
| 📊 Multiple Linear Regression | Predicts output using multiple independent features. |
| 📉 Logistic Regression | Classification algorithm for binary and multi-class problems. |
| 🌳 Decision Tree Classifier | Tree-based classification model. |
| 🌲 Random Forest Classifier | Ensemble learning using multiple decision trees. |
| 👥 K-Nearest Neighbors (KNN) | Classifies data based on nearest neighbors. |
| 🔍 Naive Bayes | Probabilistic classification algorithm based on Bayes' theorem. |
| 🚀 AdaBoost & Gradient Boosting | Ensemble boosting techniques for improved accuracy. |
| 🧠 Artificial Neural Network (ANN) | Neural network implemented using Backpropagation. |
| 🔹 Single Layer Perceptron | Basic neural network for binary classification. |
| 🎯 K-Means Clustering | Unsupervised clustering algorithm. |
| 🌸 Flower Width Prediction | Regression example using the Iris dataset. |
| 🎓 Student Performance Analysis | Machine learning analysis on student performance dataset. |
